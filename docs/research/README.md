# J-space Research Program

This directory is the working research layer for the J-space Global Workspace
Project. It sits between exploratory ideas and executable specifications.

The governing distinction is simple:

- a **source** is something we can point to;
- an **implementation** is something present in code;
- a **validation** is something that passed a recorded check;
- a **hypothesis** is a claim paired with a possible failure;
- a **speculation** is a relationship worth thinking about but not yet sharp
  enough to test;
- **mythos** is language that may help imagination but supplies no scientific
  evidence.

Research documents do not authorize model, GPU, pilot, or confirmation
execution. The Stage 2b specification and Dr. Mani's explicit authorization
remain controlling.

## Current boundary

The Jacobian Lens remains an instrument under evaluation. The 2026-07-31 Stage
2b pilot is publication-workflow stage E4, pilot observed, while remaining
scientific evidence class 1: execution succeeded and the sensitivity floor showed a
positive fitted-map-specific signal, but the preregistered primary result was
undefined because one prompt category missed its coverage minimum. No pilot
decision or thresholds were available. No hypothesis in this directory may use
J-space as a validated instrument until a robust instrument-specificity result is
confirmed under preregistered inference.

The full 200-prompt stimulus manifest is public, but the confirmation subset was
runtime-sealed and unaccessed during the pilot. Confirmation remains unauthorized.
