# Conducting Daedalus Mock Studies

Coordinate one synthetic vertical acceptance test through Daedalus, the customized EvoScientist system. Archimedes is the Hermes governance envelope. This test evaluates the bounded workflow and does not prove that every Daedalus function works.

## When to Use

Use for one complete synthetic study that must cross preparation, real Daedalus execution, independent evidence acceptance, and public-article preparation. Do not use this skill to bypass a broken stage, execute on private data, activate a provider, or publish.

## Prerequisites

- An approved synthetic-only scope.
- Direct access to the current Daedalus source and CLI help.
- A data-only work directory with no `EvoScientist/` package.
- The four stage skills listed below.

## Stage Skills

1. Use `preparing-daedalus-mock-studies` to freeze the packet and authorization.
2. Use `supervising-daedalus-mock-study-runs` to launch and monitor the real interface.
3. Use `accepting-daedalus-mock-study-evidence` to verify artifacts and assign the study verdict.
4. Use `publishing-daedalus-study-journals` to prepare a public-safe article and hold publication for Dr. Mani.

Completion criterion: each stage returns its identified output before the next transition.

## Procedure

1. Confirm the packet is synthetic, complete, immutable, and authorization-false for providers, private memory, transfer, and publication.
2. Verify the real interface and installed import path without launching a study.
3. Launch only after execution is explicitly authorized for the frozen packet.
4. Preserve native events, stderr, status, authoritative run and thread identities,
   supervisor-cycle timing, artifacts, and retries. Semantic workflow-stage
   coverage is mapped independently during acceptance from resolvable evidence.
5. Accept evidence independently. Never manufacture missing Daedalus content or upgrade `partial`, `failed`, or `stopped` to `accepted`.
6. Prepare the public article from the terminal verdict. Stop at `awaiting_dr_mani_approval` until Dr. Mani reviews the final article.

Completion criterion: the state follows `references/state-contract.md`, and every transition cites direct evidence.

## Pitfalls

- A healthy listener is not a completed study.
- A polished Daedalus message is not an artifact inventory.
- A checksum proves identity, not review coverage.
- An accepted vertical test is not full-system validation.
- Article preparation is not publication authorization.

- Confirm every terminal study verdict can proceed to an outcome-accurate article.
